# rallyreel.net

The RallyReel website: home page, user guide, support and privacy policy.
Plain HTML and CSS, hosted free on GitHub Pages.

## Before publishing
After Beta App Review approves your first build, replace `https://testflight.apple.com/join/REPLACE-ME`
in `index.html` (two places) with your TestFlight public link.

## Pages
- `/` home page
- `/guide/` user guide (the app's "User guide" link)
- `/support/` support (App Store Connect's support URL)
- `/privacy/` privacy policy (App Store Connect's privacy policy URL)
